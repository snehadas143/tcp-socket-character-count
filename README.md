# TCP Socket Character Count Program

This project implements a TCP Client-Server application in C.

## Description

* The client sends a string to the server.
* The server counts the number of characters in the string.
* The result is sent back to the client and displayed as output.

## Files

* `client.c` - Sends the input string to the server.
* `server.c` - Processes the string and counts the characters.

## How to Run

1. Compile the programs:

   * `gcc server.c -o server`
   * `gcc client.c -o client`
2. Run the server.
3. Run the client.
4. Enter a string from the client and view the output.
